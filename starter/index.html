When a pack includes a reward code, open the pack and reveal its code here. Enter the code in the in-game Cash Shop on the same account. Your server decides which rewards are available.

A few things to know

Cards stay in your collection

Once opened, a pack becomes cards. Duplicate cards are counted together, so your collection stays easy to browse.

Collecting comes first

Packs contain collectible cards by default. Your server can choose to add reward codes; any included rewards are shown before you buy.

Need a hand?

Use Refresh if balances or code status look out of date. If a purchase is interrupted, check the saved purchase instead of buying again. Contact your server team if it remains pending.
